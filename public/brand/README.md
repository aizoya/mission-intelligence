# Optional private identity assets

No logo or mascot imagery is included in this public code release. For an authorized local installation, use approved original aizoya-master-logo.jpeg, aizoya-wordmark.svg, grace.webp and errands.png here. These files are ignored by Git and retain separate rights. The app hides absent images and displays character names; it does not generate replacement artwork.

Character motion is a CSS treatment driven by saved mission status, not a rigged character animation. The reviewer uses a neutral interface symbol rather than an invented official mascot.
