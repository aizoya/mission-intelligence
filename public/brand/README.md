# Optional private identity assets

No logo or mascot imagery is included in this public code release. For an authorized local installation, use approved original aizoya-master-logo.jpeg, aizoya-wordmark.svg, grace.webp, errands.png, clue.png and prism.png here. These files are ignored by Git and retain separate rights. The app hides absent images and displays character names; it does not generate replacement artwork.

Character motion is a CSS treatment driven by saved mission status, not a rigged character animation. Clue is the founder-requested original evidence detective, generated October 17, 2026. The artwork is a transparent cutout; CSS movement follows reviewer workflow state.

Prism is an original founder-requested robot professor and report presenter, generated October 17, 2026. His interface presents saved report data deterministically; he is not a fourth model invocation or independent verifier.
